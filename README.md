> **Portfolio note:** This repository is designed to demonstrate practical skills in computational linguistics, NLP, sequence-to-sequence modelling, experiment design, evaluation, testing, and reproducibility. The bundled dataset is **synthetic/rule-generated** and should not be presented as a large real-world Bengali corpus.

## Project overview

This project maps a Bengali surface word to a morpheme-segmented representation:

```text
Input:  করছি
Output: কর+ছি
```

It implements the complete pipeline:

1. Linguistically motivated synthetic data generation
2. Character-level Bengali tokenization
3. Transformer encoder-decoder modelling from scratch
4. Train/dev/test evaluation
5. Exact-match and morphology-aware boundary metrics
6. CLI inference
7. Unit tests and GitHub Actions CI
8. Reproducible configuration and experiment logging
9. Data card and model card documenting limitations

The project intentionally avoids a pretrained checkpoint so the architecture and training pipeline remain easy to inspect.

## Why Bengali morphology?

Bengali is a morphologically rich Indo-Aryan language. Grammatical information can be expressed through inflection, case marking, plurality, classifiers, and person/register marking.

For an NLP engineer, morphological segmentation is useful as a compact sequence-to-sequence task because it connects:

- linguistic analysis
- Unicode text processing
- neural sequence modelling
- evaluation methodology
- low-resource NLP research

## Architecture

The default model is a small character-level Transformer:

```text
Bengali surface form
        │
        ▼
Unicode character tokenizer
        │
        ▼
Transformer Encoder
        │
        ▼
Transformer Decoder
        │
        ▼
Morpheme sequence
```

Default configuration:

- Character-level vocabulary
- Shared source/target embeddings
- Sinusoidal positional encoding
- 3 encoder layers
- 3 decoder layers
- 4 attention heads
- 128-dimensional hidden representation
- 256-dimensional feed-forward layer
- Autoregressive greedy decoding

## Dataset

The included dataset is generated by `data/generate_data.py` from explicitly defined morphological paradigms.

Each row contains:

```text
surface_form    segmented_form    gloss
```

Example:

```text
করছি    কর+ছি    do+PROG.1P
```

### Important scientific limitation

This is **not** a claim that the generator represents the complete Bengali morphological system. It is a controlled benchmark for demonstrating the modelling pipeline.

The current dataset is deliberately small and rule-derived. It does not adequately represent:

- irregular morphology
- productive derivation
- compounds
- phonological alternations/sandhi
- dialect variation
- natural corpus frequency
- all Bengali tense/aspect/person paradigms

For a research-quality extension, replace the synthetic training data with manually annotated or linguistically validated corpus data and compare against strong baselines.

See [`DATA_CARD.md`](DATA_CARD.md).

## Evaluation

The project reports:

### 1. Exact-match accuracy

The complete predicted segmentation must match the gold segmentation exactly.

### 2. Character error rate (CER)

Levenshtein distance between prediction and gold output, normalized by gold length.

### 3. Boundary precision / recall / F1

Morphological boundaries are treated as positions between characters. This metric is useful because a prediction can contain the correct morpheme boundary structure even when the complete string is not an exact match.

Example:

```text
Gold:      কর+ছি
Prediction: কর+ছিই

Exact match: incorrect
Boundary evaluation: still informative
```

## Quickstart

```bash
git clone https://github.com/faisalahmedaupo/bengali-morphology-transformer.git
cd bengali-morphology-transformer

python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### Generate the dataset

```bash
python data/generate_data.py --out_dir data --seed 13
```

### Train

```bash
python src/train.py --epochs 60 --batch_size 32 --seed 13
```

### Evaluate

```bash
python src/evaluate.py --ckpt_dir checkpoints --data_dir data --split test.tsv
```

### Segment a Bengali word

```bash
python src/inference.py --ckpt_dir checkpoints --word "করছি"
```

Or use interactive mode:

```bash
python src/inference.py --ckpt_dir checkpoints
```

```text
checkpoints/
├── best_model.pt
├── vocab.json
├── config.json
```

## Suggested research extensions

The most valuable next steps are:

1. **Real Bengali morphology data**  
   Replace the synthetic dataset with a manually validated or publicly available annotated corpus.

2. **Baseline comparison**  
   Compare the Transformer with a rule-based segmenter, BiLSTM/GRU model, and a pretrained multilingual encoder.

3. **Ablation studies**  
   Test character-level vs subword tokenization, model size, and positional encoding choices.

4. **Morphological analysis**  
   Predict structured features such as tense, aspect, person, number, case, and definiteness.

5. **Generalization experiments**  
   Hold out roots during testing to measure whether the model learns productive morphological patterns rather than memorizing words.

6. **Human error analysis**  
   Build a small manually checked test set and categorize model failures.
